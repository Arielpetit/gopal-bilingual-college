# Gopal's own photos and logo

Drop the school's real files in this folder. The site uses them automatically in place of the stock photos.
Use the exact file names below (any of .jpg .jpeg .png .webp). Restart `npm run dev` after adding files.

| File name        | Where it appears                          | Best shape |
|------------------|-------------------------------------------|------------|
| `logo`           | Menu, footer, dashboard (replaces crest)  | square, transparent PNG/SVG |
| `hero`           | Home page, large photo                    | portrait / square |
| `hero-2`         | Home page, small photo                    | portrait |
| `about`          | About: main photo                         | portrait 4:5 |
| `about-2`        | About: small photo                        | square |
| `nursery`        | Nursery card and page header              | landscape |
| `primary`        | Primary card and page header              | landscape |
| `secondary-anglophone` | Anglophone secondary card and header | landscape |
| `secondary-francophone`| Francophone secondary card and header | landscape |
| `bilingual`      | Bilingual section                         | landscape |
| `campus`         | Campus page header, building / gate       | wide landscape |
| `science-lab`    | Campus: laboratory                        | landscape |
| `computer-lab`   | Campus: computer room                     | landscape |
| `library`        | Campus: library / study hall              | landscape |
| `sports`         | Campus: sports ground                     | landscape |
| `early-years`    | Campus: nursery rooms                     | landscape |
| `admissions`     | Admissions page                           | landscape |
| `graduation`     | Call-to-action banner                     | wide landscape |
| `news-1` … `news-6` | News cards                             | landscape |
| `page-about`, `page-programs`, `page-campus`, `page-admissions`, `page-news`, `page-contact` | Page headers (optional) | wide landscape |

Tip: photos at least 1600 px wide look sharpest. Get parents' written permission before publishing photos of pupils.
